# CADers — Official Website

Official website of **CADers**, the engineering design club of Khulna University of Engineering & Technology (KUET).

---

## 🚀 Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | Next.js 14+ (App Router, TypeScript) |
| Styling | Tailwind CSS + Material Design 3 tokens |
| Animations | Framer Motion |
| Icons | Lucide React |
| Hosting | Vercel (planned) |
| Auth & DB | Supabase (planned) |
| File Storage | Supabase Storage (planned) |
| Feedback | Google Apps Script → Google Sheet (planned) |

---

## 💻 Running Locally

```bash
# 1. Install Node.js (LTS) from https://nodejs.org

# 2. Navigate to the project folder
cd /d D:\Website\CADers\caders-website    # Windows
# or
cd ~/path/to/caders-website               # macOS / Linux

# 3. Install dependencies (only the first time)
npm install

# 4. Start the dev server
npm run dev
